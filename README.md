# PokemonHnS-Lyra sprite swap
Lyra in Pokemon Heart and Soul

Just an asset swap to have Lyra (from Heart Gold/Soul Silver) as the female playable character. No gameplay changes
Tested with Pokemon HnS 1.21, but I dont see why it wouldnt work with any previous  or future versions

Instructions:
-Download the Pokemon Heart and Soul development repo from (https://github.com/PokemonHnS-Development/pokemonHnS)

-Copy the "graphics" folder from this repo into the HnS repo. If asked, merge all folders, and replace all files

-Compile the HnS repo, then use the resulting pokemonHnS.gba file in your favorite emulator (The process of compiling is somewhat complicated. There are more in depth directions in the HnS readme, and here: https://github.com/pret/pokeemerald/blob/master/INSTALL.md)

-Enjoy

Credits: I used kisirokitsune's sprites as a basis for lyras colors, and copied many of their sprites (https://www.deviantart.com/kisirokitsune/art/HGSS-Girl-Completed-Sheet-136710154). 
I also used the existing Kris sprites from HnS for reference and how to position the sprites (Cesare_CBass, AveonTrainer, PurpleZaffre, BatimaTheBat)
